# MENIQ Quiz Funnel

Men's health quiz funnel for MaxRx affiliate traffic.

## Stack: Next.js 14, React 18, zero external UI deps

## Dev
```bash
npm install && npm run dev
```

## Deploy to Vercel
1. Create new repo, push these files
2. Import repo in vercel.com
3. Framework: Next.js | Root: / | Build: next build | Output: .next
4. Deploy
